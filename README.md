# ✂️ SnipCut

**A lightweight media editing tool built for speed and precision.**

SnipCut provides essential video and audio editing features without the complexity and resource overhead of traditional video editors.

</div>

---

## ✨ Features

- ✂️ Fast and precise video/audio trimming
- 🔗 Merge multiple media files seamlessly
- 🎵 Extract audio from video files
- 📦 Batch processing for multiple files
- ⚡ Lightweight and efficient with minimal resource usage
- ⌨️ Keyboard-first workflow for maximum productivity
- 📤 Quick export with reliable performance

---

## 🚀 Getting Started

### Download

Go to the [Releases](https://github.com/Rohit5984/SnipCut/releases/tag/1.0.0) page and download the latest version for your operating system.


## 📖 Usage

1. Open SnipCut.
2. Import one or more video or audio files.
3. Choose an action: trim, merge, extract audio, or batch process.
4. Select your output settings.
5. Export the processed media.
