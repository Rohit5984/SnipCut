# SnipCut

SnipCut is a lightweight media editing tool built for speed and precision. It provides essential editing features without the complexity and resource overhead of traditional video editors.

Whether you need to trim clips, merge multiple files, extract audio, or process media in batches, SnipCut delivers a fast, keyboard-driven workflow with near-zero idle resource usage.

## Features

- ✂️ Fast and precise video/audio trimming
- 🔗 Merge multiple media files seamlessly
- 🎵 Extract audio from video files
- 📦 Batch processing for multiple files
- ⚡ Lightweight and efficient with minimal resource usage
- ⌨️ Keyboard-first workflow for maximum productivity
- 📤 Quick export with reliable performance
